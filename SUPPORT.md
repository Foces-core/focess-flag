# Getting Support

Before asking for help, check the README and search existing issues to see if
your question has already been answered.

## Where to ask

- **Bug in the project:** open an issue using the bug-report template. Include
  steps to reproduce, what you expected, what happened, and relevant
  environment details. Remove secrets and personal data first.
- **Feature idea:** open an issue using the feature-request template. Explain
  the problem you are trying to solve and the outcome you would like.
- **Question or usage help:** open a GitHub issue with a clear question if no
  more appropriate project discussion channel is available. Keep the question
  focused and include enough context to understand it.
- **Security vulnerability:** do not open a public issue. Follow
  [SECURITY.md](SECURITY.md) instead.
- **Conduct concern:** contact a repository code owner privately; see
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This is a community-maintained project, and response times are not guaranteed.
Please be patient and keep follow-up messages constructive.
